# Geekdino-5

> **GEEKDINO TAB 5** &mdash; One tablet. Every kind of work.  
> Cinematic 3D product showcase and commercial enquiry portal by **Geek Dino Labs**, Coimbatore.

---

## 🌟 Key Features

- **Interactive 3D Tablet**: High-fidelity Three.js WebGL 3D model with chamfered aluminum chassis, glass reflections, studio rim lighting, and mouse/touch drag-to-rotate, with seamless fallback to CSS-3D.
- **Scroll-Driven Storytelling**: Pinned tablet rotation synchronized across the 4 Journey chapters (**Work**, **Learn**, **Create**, **Connect**).
- **3D Hardware Anatomy**: Scrubbed exploded view with interactive callouts and component inspection.
- **Hardware Specs Track**: Animated metric counters and responsive layout (pinned horizontal track on desktop, stacked on mobile).
- **Sector Solutions**: Purpose-built workflows for **Education & Schools**, **Logistics & Field Fleets**, and **Enterprise CRM & Retail POS** with interactive device previews.
- **Hardware Benchmark**: Side-by-side comparison table vs legacy and generic alternatives.
- **Interactive FAQ & Trust**: Verified metrics, institutional testimonials, and accessible FAQ accordion.
- **Instant Quote Portal**: Real-time validated commercial enquiry form with 1-click WhatsApp quote generator (`+91 82200 01821`).

---

## 🛠️ Tech Stack

- **Libraries**: Three.js, GSAP 3.12.5, ScrollTrigger, Lenis smooth scroll (all self-hosted & pinned)
- **Styling**: Consolidated production CSS with dark OLED design system (`#050607`, `#3CF5A0`)
- **Assets**: Optimized WebP textures & vectors (first load < 1 MB)

---

## 🚀 Running Locally

You can serve the static site using Python or Node:

```bash
# Python 3
python -m http.server 3000

# or with npx serve
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
